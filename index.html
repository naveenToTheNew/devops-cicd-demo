Core practices

What this assignment covers

Continuous Integration

Every commit runs lint, unit tests, and a static site build so broken artifacts never reach the host.

Continuous Delivery

Merges to main produce a versioned artifact and a repeatable deploy to staging, then production.

Infrastructure as Code

Servers, buckets, and DNS stay in version control so environments can be rebuilt from a single source of truth.

Observability

Health checks, access logs, and a simple status page make failures visible before users report them.

Delivery flow

From commit to production

  1. Commit Push to the assignment repo
  2. Build Package HTML, CSS, and JavaScript
  3. Test Validate links and markup
  4. Release Publish the static artifact
  5. Deploy Serve with Nginx or S3

Runtime

Static by design

No backend, no database, no build step required. Open index.html or drop the folder behind any web server.

  • HTML5 semantic markup
  • CSS custom properties
  • Vanilla JavaScript
  • Works offline after first load of fonts
